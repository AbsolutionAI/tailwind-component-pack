# Tailwind Component Pack

**30+ production-ready Tailwind CSS components — copy, paste, ship.**

Navigation, hero sections, feature grids, pricing tables, testimonials, CTAs, forms, buttons, badges, cards, alerts, modals, blog cards, footers — all with dark mode and responsive design.

## Usage

Open `index.html` in a browser to browse the catalog. Open any file in `components/` to view and copy the source.

Each component is a self-contained HTML snippet. No build step required.

## What's included

- Navigation (2 variants)
- Hero sections (2 variants)
- Content sections (features grid, alternating rows, stats, trust bar)
- Pricing tables (3 tiers with popular badge)
- Testimonials (grid + featured)
- CTAs (3 variants)
- Forms (contact, newsletter, login)
- UI elements (button variants, badges, cards, alerts, modal)
- Blog cards
- Footers (2 variants)

## Customization

Edit the Tailwind config in `index.html` to change the primary color. All components use the `primary-*` color scale.
